# Валидация подбора

Сгенерировано автоматически `scoring/validation/matching.py`. 40 потребностей × 60 кандидатов; релевантен кандидат с истинной релевантностью ≥ 2 из 3. Самоописание шумит: в резюме к истинным навыкам добавлено 1-4 лишних; 80% кандидатов прошли тест, у 40% есть результаты ФСП (независимо от релевантности). Доля завышающих грейд неизвестна, поэтому результаты: для нескольких её значений. ДИ: бутстреп по потребностям.

## Fairness: кандидаты без ФСП
