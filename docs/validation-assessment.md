# Валидация механики тестирования

Сгенерировано автоматически `scoring/validation/assessment.py`. Синтетические кандидаты: 300 на каждый из 5 грейдов, истинный θ равномерно в диапазоне грейда. Правило: грейд подтверждён, если θ̂ − 0.25·SE ≥ порога; θ̂: EAP с априорным N(0, 1.25²). Если порог ближе одной SE к оценке, попытка продлевается на 5 заданий у порога, не больше 2 раз. Банк: 78 семейств.

## Стабильность в реалистичной популяции

θ ~ N(0, 1), каждый заявляет свой истинный грейд. У порогов людей меньше, чем при равномерном распределении внутри грейда, поэтому общая стабильность выше; у самого порога решение остаётся почти монеткой при любом тесте.

## Абляции и чувствительность (`backend`)

τ: стандартное отклонение сложности экземпляра от сложности семейства: ответы моделируются с b + N(0, τ²), а оценка, как в сервисе, знает только b семейства. Без данных пилота τ неизвестна; по литературе об автоматической генерации заданий разумный диапазон 0.2-0.4.
